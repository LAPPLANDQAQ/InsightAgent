# Evaluation

Implemented metric groups:

- Retrieval: Hit@k, MRR, nDCG@k.
- Citation: citation validity from `[ev_xxx]` refs.
- Report quality: dimension coverage and unsupported claim count.
- Harness: tool success rate, agent success rate, error count, TODO completion rate.
- RAGAs-style local fallback: faithfulness, answer relevance, context precision.

Target metrics are design goals only. Measured metrics should stay `TBD` unless produced by committed evaluation output.
