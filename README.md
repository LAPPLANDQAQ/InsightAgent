# InsightAgent v4

InsightAgent is a local TODO-driven RAG research agent for competitive and public-source analysis.
It runs a FastAPI backend, a Streamlit demo UI, a LangGraph agent workflow, evidence-aware RAG
helpers, a safe-by-default MCP adapter, and local evaluation utilities.

## Scope

Stable local runtime goals:

- DeepSeek-only runtime LLM provider.
- SQLite-backed default task database and cache.
- Safe web fetch path with SSRF checks, DNS checks, redirect checks, response-size limits, and content-type limits.
- Agent orchestration through `Planner -> Researcher -> Analyst -> Writer -> Critic`.
- Optional feature-flagged RAG path through `ResearchRouter`, `RAGIndexer`, `RAGResearcher`, and `TaskSummarizer`.
- Read-only MCP tools by default.
- Local tests with fake or stubbed LLM, search, fetch, and MCP behavior.

Out of scope for the stable local release: new model providers, auth, payment, cloud deployment,
message queues, vector databases, browser automation tests, and frontend framework migration.

## Tech Stack

- Python 3.12
- FastAPI
- LangGraph
- Pydantic v2
- SQLAlchemy 2.x
- HTTPX
- Streamlit
- SQLite
- DeepSeek via the OpenAI-compatible SDK transport

## Architecture

```text
api -> services -> graph -> agents -> tools/rag/harness/mcp_server -> infra
```

Important boundaries:

- `agents/` orchestrate only and do not call external SDKs, HTTP clients, databases, or filesystem side effects directly.
- Runtime model names are centralized in configuration and must be one of the allowed DeepSeek models.
- The OpenAI SDK is used only inside `app/infra/llm/deepseek_client.py` as a DeepSeek-compatible transport.
- Tests avoid real LLM APIs, real search APIs, real web pages, real LangFuse services, and real MCP clients.

## Local Setup

Create and activate a Python 3.12 virtual environment:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Linux or macOS:

```bash
source .venv/bin/activate
```

Install the project with development tools:

```bash
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

Optional MySQL experiment support is not installed by default:

```bash
pip install -e ".[mysql]"
```

## Environment

Copy `.env.example` to `.env` and fill only local runtime values.

Required for live DeepSeek-backed runs:

```env
LLM_PROVIDER=deepseek
LLM_BASE_URL=https://api.deepseek.com
DEEPSEEK_API_KEY=your_deepseek_key_here
LLM_HEAVY_MODEL=deepseek-v4-pro
LLM_LIGHT_MODEL=deepseek-v4-flash
LLM_FALLBACK_MODEL=deepseek-v4-flash
```

Stable defaults:

- `DB_URL=sqlite:///./data/insight.db`
- `CACHE_BACKEND=sqlite`
- `ENABLE_RAG_RESEARCH=false`
- `ENABLE_HARNESS=true`
- `ENABLE_MCP_SERVER=true`
- `MCP_ALLOW_WRITE_TOOLS=false`
- `MCP_ALLOW_LOCALHOST=false`

`TAVILY_API_KEY` may be empty. When it is empty, the Tavily provider is skipped.

## Run Locally

Start the API:

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Check readiness:

```bash
curl http://127.0.0.1:8000/healthz
```

Start the Streamlit UI in a second terminal:

```bash
streamlit run frontend/streamlit_app.py --server.port=8501 --server.address=127.0.0.1
```

If the API uses a different port, set:

```bash
INSIGHT_API_BASE=http://127.0.0.1:8000 streamlit run frontend/streamlit_app.py
```

## API Example

Create a task:

```bash
curl -X POST http://127.0.0.1:8000/api/tasks \
  -H "Content-Type: application/json" \
  -d "{\"query\":\"AI coding assistant market\",\"competitors\":[\"Cursor\",\"GitHub Copilot\"],\"dimensions\":[\"pricing\",\"features\",\"ecosystem\"]}"
```

Check status:

```bash
curl http://127.0.0.1:8000/api/tasks/{task_id}
```

Fetch the report:

```bash
curl http://127.0.0.1:8000/api/tasks/{task_id}/report
```

## Validation

Recommended local checks:

```bash
python -m compileall app
python -m ruff check app/ tests/ frontend/streamlit_app.py
python -m mypy app/ --ignore-missing-imports
python -m pytest tests/ -v
```

Optional container check when Docker is available:

```bash
docker compose build
```
